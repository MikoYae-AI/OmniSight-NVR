OpenIPC replaces closed-source Chinese camera firmware with a clean, open Linux distribution.

Features:
  • Native HTML5 video streaming with WebRTC (plays in Safari, Chrome, iOS with ZERO plugins).
  • Pure RTSP H.264 / H.265 server running on port 554.
  • Root SSH & Telnet shell access with complete privacy (no telemetry to Chinese cloud servers).

Universal Camera Compatibility Matrix

Hikvision (DS-2CD / AcuSense / DVR)

RTSP: rtsp://admin:pass@ip:554/Streaming/Channels/101

DVR Multi-Channel: BNC Ch 1 = 101, Ch 2 = 201, Ch 3 = 301.

Snapshot (No IE): http://ip/ISAPI/Streaming/channels/101/picture

Quirk: ONVIF must be enabled in Configuration > Network > Advanced > Integration Protocol.

Xiongmai (XM / NetSurveillance / Chinese DVR)

RTSP: rtsp://admin:pass@ip:554/live/ch0

DVR Multi-Channel: BNC Ch 1 = /live/ch0, Ch 2 = /live/ch1, Ch 3 = /live/ch2.

Snapshot (No IE): http://ip/snapshot.jpg

Quirk: Chinese cameras use port 34567 for desktop CMS. Admin password is often blank.

Dahua & Imou (IPC / WizSense / XVR)

RTSP: rtsp://admin:pass@ip:554/cam/realmonitor?channel=1&subtype=0

Ports: 554 (RTSP), 37777 (Dahua Management)

Snapshot: http://ip/cgi-bin/snapshot.cgi?channel=1

Quirk: Subtype 0 = Main Stream, Subtype 1 = Sub Stream.

TP-Link Tapo (C200 / C310)

RTSP: rtsp://user:pass@ip:554/stream1

Ports: 554 (RTSP), 2020 (ONVIF)

Quirk: Create a local "Camera Account" inside the Tapo mobile app under Device Settings > Advanced Settings > Camera Account.
