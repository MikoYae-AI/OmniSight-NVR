Universal Camera Compatibility Matrix

Hikvision (DS-2CD / AcuSense)

RTSP: rtsp://admin:pass@ip:554/Streaming/Channels/101

Channel Rule: Channel 1 Main is 101, Sub-stream is 102.

Quirk: ONVIF is disabled by default on recent firmware. Must enable in Configuration > Network > Advanced > Integration Protocol and configure Digest/Basic auth.

Xiongmai (XM / NetSurveillance)

RTSP: rtsp://admin:pass@ip:554/live/ch0

Ports: 554 (RTSP), 34567 (CMS Media), 8899 (ONVIF)

Quirk: Powers almost all unbranded "Chinese security cameras" on Amazon/AliExpress. Often has NO password on admin. Uses port 34567 for desktop CMS.

Dahua & Imou (IPC / WizSense)

RTSP: rtsp://admin:pass@ip:554/cam/realmonitor?channel=1&subtype=0

Ports: 554 (RTSP), 37777 (Dahua Management)

Quirk: Subtype 0 = Main, Subtype 1 = Sub. For Imou Wi-Fi cams, the ONVIF password is the safety code on the base sticker.

TP-Link Tapo (C200 / C310)

RTSP: rtsp://user:pass@ip:554/stream1

Ports: 554 (RTSP), 2020 (ONVIF)

Quirk: You MUST create a local "Camera Account" inside the Tapo mobile app under Device Settings > Advanced Settings > Camera Account.
