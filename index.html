🛡️ Legacy Camera & Internet Explorer ActiveX Fixer

Do you have older Hikvision (firmware < v5.5) or unbranded Chinese cameras that throw "Please use 32-bit Internet Explorer" or "Install WebComponents / ActiveX plugin"? Here is how OmniSight frees you from Internet Explorer forever:

Method 1: Direct HTML5 Snapshot Polling (Zero ActiveX Needed)

Older cameras only enforce ActiveX for their browser GUI. Under the hood, their raw snapshot and MJPEG endpoints can be viewed in any modern browser!

Hikvision Snapshot URL: http://[user]:[pass]@[ip]/ISAPI/Streaming/channels/101/picture

Chinese XM / NetSurveillance: http://[user]:[pass]@[ip]/snapshot.jpg

Dahua Legacy: http://[user]:[pass]@[ip]/cgi-bin/snapshot.cgi?channel=1

Method 2: Microsoft Edge "Internet Explorer Mode"

If you need to change hardware settings (IP, date, admin pass) on an ancient camera that strictly requires ActiveX:

  1. Open Microsoft Edge.
  2. Go to edge://settings/defaultBrowser.
  3. Turn "Allow sites to be reloaded in Internet Explorer mode" to Allow.
  4. Add your camera's IP (e.g. http://192.168.1.64) to the IE Mode Pages list.
  5. Restart Edge — the camera's original ActiveX setup will load!

Method 3: Portable Legacy Browsers (Linux & Modern PC)

If you run Linux (Arch, Mint, Ubuntu) and have no Internet Explorer:

  • Use Supermium or Pale Moon (32-bit) with NPAPI plugin support.
  • Or run the camera's CMS software via Wine: wine General_CMS.exe.
  • Or simply run OmniSight locally with ./start.sh to tap the RTSP feed directly.

Method 4: Bypass Mixed Content on GitHub Pages

Because GitHub Pages uses https://, modern browsers block direct HTTP requests to local IPs (e.g. http://192.168.1.x).

To bypass:

  • Click the padlock icon in your browser URL bar > Site Settings > Set Insecure content to Allow.
  • Or run the local OmniSight hub: ./start.sh 8080 for zero CORS/SSL friction.

Universal Camera Compatibility Matrix

Hikvision (DS-2CD / AcuSense / DVR)

RTSP: rtsp://admin:pass@ip:554/Streaming/Channels/101

DVR Multi-Channel: BNC Ch 1 = 101, Ch 2 = 201, Ch 3 = 301.

Snapshot (No IE): http://ip/ISAPI/Streaming/channels/101/picture

Quirk: ONVIF must be enabled in Configuration > Network > Advanced > Integration Protocol.

Xiongmai (XM / NetSurveillance / Chinese DVR)

RTSP: rtsp://admin:pass@ip:554/live/ch0

DVR Multi-Channel: BNC Ch 1 = /live/ch0, Ch 2 = /live/ch1, Ch 3 = /live/ch2.

Snapshot (No IE): http://ip/snapshot.jpg

Quirk: Chinese cameras use port 34567 for desktop CMS. Admin password is often blank.

Dahua & Imou (IPC / WizSense / XVR)

RTSP: rtsp://admin:pass@ip:554/cam/realmonitor?channel=1&subtype=0

Ports: 554 (RTSP), 37777 (Dahua Management)

Snapshot: http://ip/cgi-bin/snapshot.cgi?channel=1

Quirk: Subtype 0 = Main Stream, Subtype 1 = Sub Stream.

TP-Link Tapo (C200 / C310)

RTSP: rtsp://user:pass@ip:554/stream1

Ports: 554 (RTSP), 2020 (ONVIF)

Quirk: Create a local "Camera Account" inside the Tapo mobile app under Device Settings > Advanced Settings > Camera Account.
